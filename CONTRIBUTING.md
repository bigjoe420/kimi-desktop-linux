# Contributing

Thanks for your interest in improving Kimi Desktop for Linux.

## Issues

Before opening a pull request, please open an issue to discuss the change. This keeps the project focused and avoids wasted effort.

## Pull Requests

1. Fork the repository and create a feature branch.
2. Make your changes with clear, minimal commits.
3. Ensure the build passes locally: `./build.sh`
4. Open a PR referencing the related issue.

## Code Style

- Rust: follow `cargo fmt` and `cargo clippy`.
- Comments explain *why*, never *what*.
- No new dependencies without justification.
